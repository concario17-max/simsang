# 심상 서재

영성 달력, 요가수트라와 여섯 문헌을 함께 읽는 정적 사이트입니다. 별도 빌드 없이 저장소 최상위를 웹 서버로 제공하세요. JSON을 읽으므로 파일을 더블클릭하는 방식은 지원하지 않습니다.

## 수록 범위

| 문헌 | 본문 항목 | 해설 | 만화 연결 항목 |
|---|---:|---:|---:|
| 바가바드 기타 | 640 | 640 | 640 |
| 보리도등론 | 70 | 70 | 70 |
| 장미십자의 비의 | 995 | 338 | 339 |
| 기적수업 | 291 | 291 | 291 |
| 인위삼신행상명등론 | 168 | 0 | 69 |
| 티베트 사자의 서 | 331 | 1 | 52 |

만화 연결 항목 수는 이미지 파일 수와 다릅니다. 여러 항목이 한 이미지를 공유할 수 있습니다. 티베트 사자의 서는 기도문 52항목과 본문 279항목, 음원 앨범 7개를 포함합니다.

- 보리도등론은 도입부·68게송·결어만 포함합니다. 난처석은 이번 통합 범위에서 제외했습니다.
- 장미십자의 비의는 제작 중이므로 준비된 자료만 연결합니다.
- 기적수업의 51~60, 81~90, 111~120, 141~150, 171~180, 201~220과 부재는 원래 구성을 유지한 것입니다. 361~365과는 한 항목입니다.
- 347과 영문: “Anger must come from judgment. Judgment is The weapon I would use against myself, To keep the miracle away from me.”
- 347과 한국어: “분노는 판단에서 온다. 판단이란, 내가 기적들을 전부 몰아내려고 나 자신에게 겨누는 무기이다.”
- 기타의 translation_suk 빈 항목 60개는 그대로 유지합니다.
- 인위삼신행상명등론과 티베트 사자의 서에 남아 있던 무관한 요가수트라 해설은 수록하지 않습니다. 사자의 서 기도문 52번의 해당 해설은 유지합니다.

## 읽기 및 저장

홈에서 각 문헌의 내부 읽기 화면으로 이동합니다. 장·항목 선택, 검색, 본문·해설·만화 전환, 책갈피, 사색 노트, 이어 읽기를 지원합니다. 책갈피와 노트는 해당 브라우저에 저장되며 다른 기기와 자동 동기화되지 않습니다.

본문·번역·해설은 `data/books/`에 저장됩니다. 새 문헌의 만화·앨범 음원은 원본 저장소의 고정 커밋에 연결하므로 네트워크와 원본 파일 접근이 필요합니다. 기타의 원문 음원은 기존 외부 주소를 유지합니다. 달력·요가수트라의 기존 자료는 그대로 사용합니다.

## 원본 갱신

`data/books/sources.json`에 원본 저장소, 커밋과 수록 수가 기록됩니다. 여섯 저장소를 한 폴더 아래 각각 gita, lamp, rosi, miracle, 3body, Thodol 이름으로 체크아웃한 뒤 실행합니다.

```sh
python3 scripts/import-books.py /path/to/source-checkouts
python3 scripts/check-books.py /path/to/source-checkouts
```

특정 문헌만 가져오려면 원본 폴더 뒤에 문헌 이름을 지정합니다. 갱신 후 변경 내용을 검토하고 커밋하세요.


## 다카하시 신지 자료실

홈의 신지 자료실에서 이야기 237편·만화, 도서 3권 80항목, 영상 47개를 이용할 수 있습니다. 본문과 코드는 `shinji/`에 수록했으며 만화는 원본 저장소의 고정 커밋에 연결합니다. 원본 저장소는 수정하지 않았습니다. 출처와 교정 횟수는 `shinji/source.json`에 기록합니다.

이야기와 전자책은 이동한 항목의 주소를 갱신합니다. 전자책은 항목별 스크롤 위치를 같은 브라우저에 저장하고, 선택한 책의 본문 검색과 책갈피 필터를 지원합니다. 신지 원본 사이트의 저장 기록은 자동 이전되지 않습니다.

본문은 `습니 다`, `입니 다`, `있습 니다`의 명확한 분리 오류 362곳만 교정했습니다. 짧은 강의의 내용과 순서는 보존했습니다. 영상별 강연록 대응은 검증되지 않았으므로 임의로 연결하지 않았습니다.
