# 심상 서재

메인 · 영성 달력 · 요가수트라 통합본입니다.

압축을 푼 뒤 index.html과 나머지 폴더를 함께 저장소 최상위에 넣으세요. ZIP 파일 자체를 올리는 방식이 아닙니다.

정적 웹사이트이며 별도 빌드가 필요 없습니다. 로컬 파일을 더블클릭하면 JSON 자료 로딩이 제한될 수 있으므로 웹 서버에서 실행하세요.

책갈피와 사색 노트는 브라우저에 저장됩니다. 주소나 브라우저가 바뀌면 기존 기록은 자동 이동되지 않습니다.

포함: 달력 자료, 요가수트라 195구절, 학습만화 및 발음 음원. 다른 문헌은 기존 사이트 링크입니다.
