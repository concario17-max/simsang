# 풍 · 부정편 57. 다른 사람의 말을 끊음과 무례함

## 👂 내 생각이 떠올라도 끝까지 들어 봐

양해 없이 끼어들면 상대의 설명과 대화의 흐름이 끊겨. 먼저 전체 내용과 중요한 점을 이해한 뒤 질문하고 의견을 나누는 태도가 필요해.

## 🔗 이어지는 흐름의 가치를 알아

끊어진 사슬에 비유해 말과 작업, 훈련의 연속성을 설명해. 필요한 단계를 빠뜨리면 전체 결과에도 빈틈이 생길 수 있어.

## 🤝 질문할 때도 적절한 순간을 찾아

질문과 토론 자체가 잘못은 아니야. 긴급한 확인과 안전 문제가 있다면 중단이 필요할 수도 있어. 상황과 약속한 대화 방식에 맞춰 존중하며 말하고 들으면 돼.
