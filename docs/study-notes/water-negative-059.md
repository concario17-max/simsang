# 수 · 부정편 59. 집착

## 🪢 중요한 문제가 마음을 밤낮으로 붙잡아

생계의 걱정과 관계, 음악과 예술처럼 좋은 것에도 지나치게 사로잡힐 수 있어. 같은 생각이 반복되며 실제 문제 해결과 평온을 방해하는지 살펴.

## 🔍 현실과 불필요한 반복을 구별해

필요한 정보를 확인하고 상식에 따라 대응해. 직장에서 부당한 대우가 있다면 설명과 이의 제기, 지원과 환경 변경 같은 실제 방법도 고려해.

## 🎯 관심을 의식적으로 선택해

좋아하고 즐기는 것을 버리는 게 아니라 자신의 한도를 지키는 거야. 생각을 억지로 모두 없애려 하기보다 현재 활동으로 돌아와. 건강한 애정과 몰입을 무조건 의존으로 보지는 않아.
