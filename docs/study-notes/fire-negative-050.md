# 화 · 부정편 50. 타인의 의견을 무시함

## 👂 다른 관점은 자신을 비추는 거울이야

남의 의견이 마음에 들지 않아도 무엇을 말하는지 살펴볼 가치는 있어. 자기 행동과 반응을 알아보거나 위험을 피하는 경고가 될 수 있거든.

## 🔍 듣는 것과 그대로 따르는 것은 달라

상대의 제안이 현실적인지, 자신을 이용하려는 의도가 있는지 검토해. 말에 붙은 기분과 인상에만 끌리면 내용을 살피지 않은 채 행동하기 쉬워. 무엇을 요구하고 어떤 결과가 생길지 분석해 봐.

## 🪞 내관의 재료로 활용해

옳은 의견은 배우고, 잘못된 의견도 내 반응을 살피는 계기로 삼아. 다른 사람을 통해 드러나는 여러 생각과 감정의 의미를 이해하면서 원소적 특성을 다루는 힘을 길러 가는 거야.
