# 지 · 부정편 33. 인색함

## 💰 모으지만 쓰지 못하는 상태

필요한 지출과 도움까지 아까워하면서 재산을 늘리는 일에만 매달리면 돈이 주인이 되기 쉬워. 가진 액수보다 무엇을 위해 모으고 있는지 살펴봐야 해.

## 📚 앎을 움켜쥐는 인색함

돈뿐 아니라 지식과 경험도 혼자만 쥐고 있을 수 있어. 새로 온 사람이 배워야 할 업무를 일부러 알려 주지 않으면 모두의 일이 어려워져. 정당한 권리와 비밀을 지키는 일과는 구별해야 해.

## 🤲 형편에 맞게 나누기

필요한 곳에 쓰고 맡은 정보는 책임 있게 전달하는 연습을 해 보자. 너그러움이 무절제한 낭비일 필요는 없어. 가난한 사람이 과거에 인색했을 거라고 추측하지 말고 지금의 필요를 보면 돼.
