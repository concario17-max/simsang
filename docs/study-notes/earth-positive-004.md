# 지 · 긍정편 4. 균형

## ⚖️ 여러 특성을 고르게 다루는 힘이야

일과 관계, 생각과 감정에서 지나친 반응을 줄이고 상황에 맞게 대응해. 이를 완전한 원소적 균형으로 나아가는 기본 성품으로 봐.

## 🪞 자극을 알아보고 반대 작용을 길러

해로운 관념이 들어오면 무엇을 요구하는지 살펴보고 평온과 유익한 태도로 대응해. 군중의 흥분 속에서도 자신의 판단을 유지하는 데 도움이 돼.

## 🧭 균형을 무오류의 선언으로 쓰지 않아

타인의 본성을 정확히 읽거나 모든 상황을 완전히 통제한다고 단정하지 않아. 현실의 변화와 자신의 한계를 인정하며 대응을 조정해. 자신과 이웃에게 유익한 목적을 지키는 게 중요해.
