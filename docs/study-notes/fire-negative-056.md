# 화 · 부정편 56. 무력한 자기연민을 동반한 교만

## 🏰 우월하다는 믿음이 무너지면 슬픔으로 바뀌어

가까운 사람이 사실을 말하거나 지위가 흔들릴 때, 교만했던 사람이 깊은 자기연민에 빠질 수 있어. 자신의 행동보다 잃어버린 존경과 대우를 슬퍼하는 거야.

## 🪞 억울함 뒤에 숨은 기대를 봐

“왜 나를 예전처럼 높여 주지 않을까”라는 마음이 자신의 냉혹함과 무시하는 태도를 가릴 수 있어. 자기연민이 교만을 바꾸는 대신 보호하고 있는지 살펴봐.

## 🌱 겸손을 배우는 쪽으로 돌아서

다시 우월해지려고 애쓰기보다 정당한 지적을 받아들이고 관계를 고쳐. 겸양과 자기 인식이 전환점이 돼. 가혹한 고통만이 유일한 배움의 길이라고 생각할 필요는 없어.
