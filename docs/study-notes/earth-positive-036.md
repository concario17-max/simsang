# 지 · 긍정편 36. 자신의 잘못을 올바르게 평가하기

## 🪞 고백만으로 변화가 완성되지는 않아

잘못을 말로 인정해도 행동이 그대로면 같은 결과가 이어질 수 있어. 무엇을 고칠지 정하고 실천해야 해.

## 🛠️ 원인과 영향을 구체적으로 살펴

자신의 선택과 습관이 어떤 문제를 만들었는지 알아보고 가능한 피해를 바로잡아. 작은 실수를 과장하지도 큰 문제를 축소하지도 않아.

## 🌱 잘못을 배움으로 바꿔

오류 가능성은 누구에게나 있어. 실수가 자신의 가치 전체를 결정하지는 않아. 내관으로 부족한 부분을 알아내고 다음에 다르게 대응할 방법을 길러.
