# 지 · 부정편 14. 허술한 방어

## 🛡️ 피하기만 해서는 반복될 때

문제를 잠깐 외면했어도 같은 상황에서 계속 흔들린다면 대처 방법을 더 구체적으로 세워야 해. 무엇이 나를 자극하고 어떤 순간에 결심이 무너지는지 알아보는 게 먼저야.

## 🧭 상황에 맞는 경계 세우기

부당한 요구에는 역할과 한계를 분명히 말하고, 분노가 커질 때는 거리를 두며 진정할 수 있어. 상대를 깎아내리거나 나이와 질병을 혐오하는 상상으로 욕망을 억누를 필요는 없어.

## 🌱 효과 있는 방법으로 바꾸기

내관은 반복되는 원인과 대응을 살피는 데 써 보자. 단호함은 공격성과 다르고 온화함은 무조건 양보하는 것과 달라. 친절하게 말하면 반드시 상대가 사과한다는 기대보다 내 안전과 행동을 지키는 데 집중해.
