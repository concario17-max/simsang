# 화 · 부정편 42. 무모함

## 🕳️ 결과를 보지 않고 뛰어들어

생각할 시간이 있는데도 상황과 위험을 살피지 않고 즉시 결정하는 태도야. 감정과 이기심이 판단을 덮으면 자신뿐 아니라 주변 사람의 건강과 재산도 위험해질 수 있어.

## 🔍 평온하게 전체를 검토해

어떤 조건이 있고 무엇이 뒤따를지 함께 봐. 충동이 시키는 대로 움직이기보다 배운 경험을 써서 선택해. 실패 뒤의 실망과 자기연민으로 끝내지 말고 다음 행동을 바꾸는 교훈으로 삼아.

## ⚡ 빠른 판단과 무모함은 달라

즉시 대응해야 하는 상황도 있어. 이때는 훈련된 사고와 기지로 상황을 빠르게 분석해야 해. 직관과 영감을 중시하는 영적 관점이지만, 순간적인 확신을 언제나 옳은 판단으로 여겨서는 안 돼.
