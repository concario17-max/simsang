# 지 · 긍정편 44. 너그러움

## 🤲 가진 것을 기쁘고 사심 없이 나눠

물질과 경험, 지식과 우정의 여러 형태로 베풀 수 있어. 상대를 찾아온 손님처럼 존중하며 가능한 좋은 것을 나누는 태도야.

## 🌱 자신에게 필요한 몫도 돌봐

여력이 부족하면 먼저 몸과 마음, 역량을 기르는 데 힘을 써. 남을 돕겠다고 자신의 기본 생활을 무너뜨릴 필요는 없어.

## ⚖️ 계산된 베풂과 구별해

내준 것보다 더 큰 보답을 요구하면 거래에 가까워져. 도움의 목적과 실제 필요를 살피고 상대를 지배하지 않아. 너그러우면 반드시 몇 배의 재산과 행운이 돌아온다고 기대하지도 않아.
