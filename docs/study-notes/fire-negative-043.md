# 화 · 부정편 43. 탐욕

## 🪙 더 가져도 충분해지지 않아

돈과 물건뿐 아니라 명예와 권력도 끝없이 탐할 수 있어. 남의 마지막 몫까지 빼앗아 자기 만족을 채우려 하면 연민과 절제가 밀려나지.

## 🌍 개인의 욕심이 집단을 움직이기도 해

탐욕이 지배와 착취로 번지면 많은 사람이 희생될 수 있어. 집단 전체가 더 많은 자원을 차지하려고 싸우는 모습도 같은 흐름으로 이해해.

## 🌾 겸양과 감사로 방향을 바꿔

지금 삶을 유지하는 것에 감사하고, 소유는 잠시 맡겨졌다는 사실을 기억해 봐. 영과 혼을 기르는 목적에 물질을 사용해. 많이 갖는 것 자체보다 무엇을 위해 모으고 누구의 몫을 침해하는지가 중요해.
