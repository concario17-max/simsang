# 풍 · 부정편 65. 정당하지 않은 변명

## 🎭 잘못을 고치기보다 작게 보이게 해

누락과 오기, 잘못된 정보를 지적받았을 때 환경과 동료만 탓하면 당장은 편해질 수 있어. 하지만 실제 작업 방식이 바뀌지 않으면 같은 문제가 반복돼.

## 🪞 설명과 책임 회피를 구별해

방해와 잘못된 정보가 실제 원인일 수는 있어. 그 사실을 확인하면서도 내가 점검하고 수정할 부분을 인정해. 원인을 설명한다고 무조건 변명이 되는 건 아니야.

## 🛠️ 확인하고 수습하며 재발을 줄여

자신이 전하는 정보와 기록을 살피고 잘못이 있으면 바로잡아. 체면을 지키는 말보다 다음에는 다르게 일할 방법을 마련하는 게 중요해.
