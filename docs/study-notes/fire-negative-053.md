# 화 · 부정편 53. 지나친 탐닉

## 🍯 즐거움이 한계를 넘어서

좋고 즐거운 것이라도 양과 빈도를 다스리지 못하면 해로워질 수 있어. 음식과 음료, 성적인 즐거움뿐 아니라 영적·멘탈적 활동에서도 지나침은 생겨.

## 🔁 반복이 습관과 격정으로 굳어져

더 많이 원하고 경고 신호를 무시하는 흐름을 살펴봐. 원소적 불균형이라는 관점에서 감정과 욕망이 의지보다 앞서가는 상태야. 작을 때 알아차리고 생활의 균형을 되찾는 게 중요해.

## ⚖️ 절제는 모든 즐거움을 없애는 게 아니야

자신에게 유익한 한도를 알고 분별 있게 사용해. 작은 잘못은 인정하고 다음 행동을 바꾸는 교훈으로 삼아. 탐닉으로 건강이나 생활에 어려움이 생겼다면 의지의 문제로만 몰지 말고 필요한 도움도 받아.
