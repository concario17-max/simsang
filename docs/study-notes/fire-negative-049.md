# 화 · 부정편 49. 조급함

## ⏩ 마음이 실제 작업보다 앞서 달려

결과를 빨리 얻으려 하면 생각과 감정, 손으로 수행하는 과정이 서로 어긋나기 쉬워. 빈틈이 생기면 수리와 보완이 늘어 오히려 목표에서 멀어질 수 있어.

## ⚙️ 각 부분이 맞물리게 진행해

계획과 실행, 시간과 공간, 감정의 흐름을 조화롭게 이어 가. 구상 없이 손만 빨라지거나 실제 진도보다 마음이 먼저 완성에 가 있는 상태를 살펴봐.

## 🌱 처음부터 꾸준히 완성도를 쌓아

중요한 과제일수록 필요한 검토와 단계를 빠뜨리지 않아. 느리게 보이더라도 성실하고 일관되게 하면 다시 만드는 낭비를 줄일 수 있어. 성급했던 경험도 다음에는 다르게 일하는 교훈이 돼.
