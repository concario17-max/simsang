# 수 · 부정편 55. 언제든 속을 수 있음

## 🔍 실수와 기만의 가능성을 기억해

연필 대신 펜을 집거나 숫자를 뒤바꾸는 작은 실수부터, 과장된 상품 설명과 거짓 정보까지 다뤄. 자신이 늘 정확히 본다고 장담하지 않아.

## ✅ 주의와 실제 확인을 함께 써

정보의 내용과 근거, 말과 현실이 맞는지 살펴봐. 중요한 작업은 검토와 기록으로 보완해. 단순한 실수를 적대적인 잠재의식의 증거로 단정하지 않아.

## 🧭 타인을 속이며 분별을 지키지는 않아

남을 속이는 행동이 신뢰와 책임에 어떤 결과를 주는지 돌아봐. 비밀을 지킬 수는 있지만 상대도 속기를 원한다며 기만을 정당화하지 않아. 신중한 공개와 정직한 판단을 함께 길러.
