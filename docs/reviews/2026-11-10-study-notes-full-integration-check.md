# 쉽게 읽기 전체 적용 확인

## 적용 범위

화·풍·수·지의 긍정편과 부정편 492개에 개별 정리글을 commentary로 연결했다. 번호 항목 491개와 공통 서론 1개다. 부록 7개는 번역 검토 자료로 유지한다. 원소 목차의 제공 형식에도 쉽게 읽기를 표시하고 검색 색인을 갱신했다. 운영 배포는 하지 않았다.

## 검증

- 가져오기 전후 commentary를 제외한 모든 항목 필드의 SHA-256이 일치한다. 한국어·영문 본문, ID와 만화 정보는 변경되지 않았다.
- 492개 정리글과 연결 데이터가 정확히 대응하며 각 항목이 통합 검색 색인에 포함되는지 자동 검사했다.
- node --test tests/*.test.mjs: 40개 통과.
- node scripts/build-discovery.mjs --check: 통과.
- 브라우저에서 화 부정편 서론, 풍 긍정편 1번·부정편 69번, 수 긍정편 36번·부정편 80번, 지 긍정편 60번·부정편 86번의 쉽게 읽기와 소제목 표시를 확인했다.
- 지 부록을 commentary 주소로 열면 본문·번역으로 전환되고 쉽게 읽기 탭은 숨겨진다.
- 지 원소 목차에서 쉽게 읽기·본문·학습만화 제공 표시와 부록의 번역 검토 자료 표시를 확인했다.
- 본문에서 정리글에만 있는 표현인 배움이 빈약한을 검색하여 지 부정편 86번 쉽게 읽기로 이동함을 확인했다.
- 시범 적용에서 확인한 모바일 소제목과 표의 가로 스크롤 스타일을 전체 정리글에도 동일하게 사용한다.

## 파일과 실행

전체 갱신 명령: node scripts/import-study-notes.mjs --all

로컬 목차: http://127.0.0.1:4173/introspection/

전체 적용 화면: output/previews/study-notes/all-earth-negative-086.png

로컬 서버가 종료되면 node tmp/study-preview-server.mjs로 다시 실행할 수 있다.
