# 자기 성찰 — 네 원소의 특성

현재 화·풍·수·지의 본문과 번역 검토 부록이 공개되어 있습니다. 사용자 제공 확정 한국어 번역과 영문 DOCX의 항목 순서를 대조하여 긍정편 40개, 부정편 62개, 부정편 서론 1개를 수록했습니다. 이 수치는 화 원소의 수록 범위입니다. 한국어 원문 문단과 목록을 유지합니다.

## 쉽게 읽기

화·풍·수·지의 긍정편·부정편 전체 492개(번호 항목 491개와 공통 서론 1개)에 docs/study-notes의 정리글을 commentary로 연결했습니다. 번역 검토 부록 7개는 정리글 대상에서 제외합니다. 본문·번역과 별도인 쉽게 읽기 탭으로 제공하며 기존 항목 ID, 본문, 영문, 만화, 책갈피·노트 저장 키는 유지합니다. 현재 로컬 적용 상태이며 운영 배포는 별도입니다.

전체 가져오기: node scripts/import-study-notes.mjs --all

일부만 갱신하려면 항목 ID를 지정합니다: node scripts/import-study-notes.mjs fire.positive.001

변경 뒤에는 기존 검색 색인 생성과 검사를 수행합니다. 쉽게 읽기가 없는 항목과 부록은 본문으로 돌아갑니다. URL의 view와 사용자가 저장한 보기 설정이 없는 첫 방문에는 쉽게 읽기를 우선 표시합니다.

`data/books/introspection.json`의 항목 ID는 기록·검색·주소에 사용합니다. 제목을 변경해도 기존 ID를 바꾸지 않습니다. 화의 예: `fire.positive.001`, `fire.negative.016`, `fire.negative.intro`. 풍은 air 접두사를 사용합니다. 수·지는 water/earth 접두사를 사용합니다.

## 학습만화 추가

이미지를 `assets/introspection/fire/negative/016/` 같은 경로에 추가한 뒤 해당 항목의 `comics`에 읽는 순서대로 넣습니다. 경로는 사이트 루트 기준으로 지정합니다.

```json
"comics": [
  {"src": "/assets/introspection/fire/negative/016/01.webp", "alt": "첫 장의 실제 내용을 설명하는 대체 텍스트"},
  {"src": "/assets/introspection/fire/negative/016/02.webp", "alt": "둘째 장의 실제 내용을 설명하는 대체 텍스트"}
]
```

비어 있으면 만화 탭은 숨겨지고 준비 중 안내가 나옵니다. 추가하면 탭과 목차의 만화 필터에 자동 반영됩니다. 이미지는 세로로 표시되며 각 장을 눌러 확대합니다. 과거 문헌의 단일 `comic` 필드도 계속 지원합니다.

내용 변경 후 `npm run build:discovery` 및 `npm run check`를 실행합니다. 새 항목을 추가할 때 한국어/영문 대응과 노트·백업 호환성도 확인합니다.

## 풍 원소

사용자 제공 Introspection_Air_KO_Polished.md의 본문과 부록을 보존합니다. 긍정편 58개, 부정편 69개를 제공된 영문 DOCX와 항목 순서대로 연결했습니다. 부정편 67의 영문 제목은 번역본 목차 쪽이 더 길지만 같은 항목이며 DOCX 본문을 그대로 수록했습니다. 마지막 air.appendix는 잠정 번역 채택 사항 29건 전체(목록·선택 이유·남은 불확실성)를 담은 한국어 번역 검토 기록입니다. 원저자의 본문이나 영문 원문으로 표시하지 않습니다.

## 화 원소 부록 업데이트

Introspection_Fire_KO_With_Appendix(1).md와 대조하여 102개 항목의 제목·한국어 본문과 서론을 확인했습니다. 기존 영문·항목 ID·만화 정보는 보존합니다. 화 본문 다음에 fire.appendix.001(용어표·문체 기준), fire.appendix.002(잠정 번역 채택 사항 13건)를 수록합니다. 두 부록은 한국어 번역 검토 자료이며 영문 원문 또는 학습만화 준비 중으로 표시하지 않습니다.

## 수 원소

Introspection_Water_KO_Complete_With_Appendix(1).md의 긍정편 36개·부정편 80개와 두 부록 섹션 전체를 보존했습니다. 원본에 포함된 잠정·보류 설명도 유지합니다. water.positive.001~036, water.negative.001~080, water.appendix.001~002를 사용합니다. 영문은 제공된 PW_168-209.pdf, NW_455-560.pdf에서 항목별로 추출했습니다. 머리말·쪽수를 제외하고 줄바꿈과 소프트 하이픈을 정리했습니다. 제목의 A가 K로 인식된 곳은 한국어 파일의 영어 제목과 PDF 제목을 대조해 경계를 식별했습니다. 원소 첫 화면과 검색·책갈피·노트·백업은 공통 구조를 사용합니다.


## 2026-11-09 제공 PDF 재대조

`pdf/`에 제공된 영문 발췌 8개(총 634 PDF 페이지)를 대조했습니다. 파일명의 시작 숫자는 첫 인쇄 쪽수보다 1 큽니다. 인쇄 쪽수와 PDF 페이지를 구분하고, 파일 SHA-256과 42건의 검토 위치는 `data/sources/introspection-pdf-review.json`에 기록했습니다. 원본 PDF 바이너리는 이번 변경에 포함하지 않습니다.

491개 특성의 영문 문단을 머리말·쪽수·분철·각주 표지와 문자 인식 차이를 구분해 비교했습니다. 지 부정편 79번에서 인쇄 667~668쪽의 머리말이 문장에 섞인 것을 제거했습니다. 기존 한국어 번역과 항목 ID는 유지합니다. 화 13건·풍 29건의 잠정 표현은 제공 PDF에도 존재하므로, 인쇄본 확인과 해석 확정을 구분하여 기존 잠정 번역을 유지했습니다. 화 부정편 서론은 제공된 8개 PDF의 범위 밖이므로 이번 원본 대조에서 제외합니다. 이 작업은 한국어 번역 전체의 의미 정확성을 보증하는 전수 교정이 아닙니다.
